\begin{abstract}
This note gives the complete derivation, with every intermediate step made explicit, of the
approximate capacity bound used in the main paper (Section 2.3): an expression for the largest
number of items $M$ a sparse $K$-of-$H$ combinatorial key-value memory can store while
remaining reliably retrievable under a given level of query corruption. The bound is
structurally the same as modern Hopfield networks' proven exponential capacity
\cite{ramsauer2020}, but is derived here for a discrete, sparse code via elementary
combinatorics and extreme value theory rather than for dense continuous patterns via an
energy-function argument. We include a full, self-contained proof of the one non-elementary
step (the expected maximum of many correlated-in-effect-but-treated-as-independent Gaussian
similarities), validate the final bound against simulation, and discuss its relationship to
the wider family of capacity theorems it belongs to. We then go further than that first-moment
approximation: Section~\ref{sec:exacttail} derives an exact, non-asymptotic failure probability
directly from the hypergeometric distribution, and a corresponding rigorous sufficient bound on
capacity at any chosen target reliability $\delta$, correcting a subtle correlation error that a
natural-looking marginalization over query corruption would otherwise introduce. This exact
bound is, as expected, considerably more conservative than the first-moment approximation, and
is shown to be tight in the well-separated regime and honestly, quantifiably loose only as the
system approaches its collapse transition.
\end{abstract}

\section{Setup}

We store $M$ items. Item $m$'s key is a binary vector $h_m \in \{0,1\}^H$ with exactly $K$
active (value-$1$) coordinates -- a $K$-of-$H$ sparse code. Throughout this note we model the
$M$ stored keys as independent, uniformly random $K$-subsets of $[H] = \{1,\dots,H\}$: an
idealization relative to the true architecture, where keys are $W_{SH}$-projections of
mutually correlated combinatorial structure (solved Sudoku grids), addressed explicitly in
Section~\ref{sec:limitations}.

A query is formed from the true key $h_{\text{true}}$ by flipping a fraction $\eta \in [0,1]$
of all $H$ coordinates, chosen uniformly at random without replacement -- the noise model used
throughout the main paper. Retrieval compares the query against all $M$ stored keys via
similarity (shared active coordinates) and should return the index of $h_{\text{true}}$.
Retrieval \emph{fails} when some other stored key's similarity to the query exceeds
$h_{\text{true}}$'s.

We ask: for fixed $H$, $K$, and corruption level $\eta$, how large can $M$ be before this kind
of failure becomes likely?

\section{Step 1: Similarity between two independent random keys}
\label{sec:step1}

\begin{lemma}[Hypergeometric overlap]
\label{lem:hypergeom}
Let $A, B \subset [H]$ be independent uniformly random subsets with $|A| = a$, $|B| = b$. Then
$|A \cap B|$ is a hypergeometric random variable with
\[
\mathbb{E}[|A \cap B|] = \frac{ab}{H}, \qquad
\mathrm{Var}(|A \cap B|) = a\cdot\frac{b}{H}\Big(1-\frac{b}{H}\Big)\cdot\frac{H-a}{H-1}.
\]
\end{lemma}

\begin{proof}[Proof sketch]
Fix $A$ and treat $B$'s $b$ elements as drawn sequentially without replacement from $[H]$.
Let $X_i = \mathbb{1}[\text{the $i$-th draw lands in } A]$, so $|A\cap B| = \sum_{i=1}^b X_i$.
Each $X_i$ is Bernoulli$(a/H)$ by symmetry, giving the mean by linearity of expectation. For
the variance, $\mathrm{Cov}(X_i,X_j) < 0$ for $i\ne j$ because sampling without replacement
makes draws negatively associated (having drawn a marked element makes drawing another
marked element on a later draw slightly less likely); summing the $b$ variances and
$\binom{b}{2}$ covariances gives the stated finite-population-corrected formula. (Full
derivation: Feller, \textit{An Introduction to Probability Theory}, Vol.\ 1, Ch.\ II.)
\end{proof}

Applying Lemma~\ref{lem:hypergeom} with $a=b=K$ gives the similarity between two
\emph{uncorrupted} stored keys: mean $K^2/H$, the number quoted throughout the main paper (e.g.\
$K^2/H = 22.5$ for the default $H=1000$, $K=150$).

\section{Step 2: Statistics of a corrupted query}
\label{sec:step2}

Flipping a uniformly random fraction $\eta$ of all $H$ coordinates is itself an instance of
Lemma~\ref{lem:hypergeom}: the $\eta H$ flipped positions are a random subset of $[H]$, and we
ask how many of $h_{\text{true}}$'s $K$ active positions they contain. By the lemma (with
$a=K$, $b=\eta H$), the expected number of active positions flipped \emph{off} is $\eta K$, so
\begin{equation}
S_{\text{true}}(\eta) \;=\; \mathbb{E}\big[\,\text{similarity of query to } h_{\text{true}}\,\big] \;=\; K(1-\eta),
\label{eq:strue}
\end{equation}
exactly (no further approximation needed: this is a direct expectation, not a bound). The
expected number of originally-\emph{inactive} positions flipped \emph{on} is, symmetrically,
$\eta(H-K)$, so the corrupted query's own total active-coordinate count is, in expectation,
\begin{equation}
K_q(\eta) \;=\; K(1-\eta) + \eta(H-K) \;=\; K(1-2\eta) + \eta H.
\label{eq:kq}
\end{equation}
The query's similarity to any \emph{other}, independent stored key is now Lemma~\ref{lem:hypergeom}
applied with $a = K_q(\eta)$, $b=K$:
\begin{equation}
\mu_{\text{other}}(\eta) = \frac{K_q(\eta)\,K}{H}, \qquad
\sigma_{\text{other}}^2(\eta) = K_q(\eta)\,\frac{K}{H}\Big(1-\frac{K}{H}\Big)\frac{H-K_q(\eta)}{H-1}.
\label{eq:muother}
\end{equation}

\section{Step 3: Gaussian approximation}
\label{sec:step3}

The hypergeometric distribution of $S_{\text{other}}$ (similarity to one specific other key) is
exact but discrete and unwieldy for the extreme-value step that follows. We approximate
\[
S_{\text{other}} \;\approx\; \mathcal{N}\big(\mu_{\text{other}}(\eta),\, \sigma_{\text{other}}^2(\eta)\big),
\]
justified for $H \gg 1$ by the central limit theorem for sampling without replacement from a
finite population \cite{erdosrenyi1959,hajek1960}: sums arising from simple random sampling
without replacement are asymptotically normal as the population size grows, with exactly the
finite-population-corrected variance already appearing in Lemma~\ref{lem:hypergeom}. This is
the least exact step in the derivation, and its error is largest precisely when $\sigma_{\text{other}}$
is small relative to the mean -- i.e.\ at low noise, where the discreteness of the underlying
hypergeometric distribution matters most. Section~\ref{sec:validation} quantifies this error
directly rather than leaving it as a caveat.

\section{Step 4: The maximum of many competitors}
\label{sec:step4}

Retrieval does not fail when the \emph{typical} competing key looks similar to the query --
it fails when the \emph{single most similar} of the $M-1$ competitors exceeds
$S_{\text{true}}(\eta)$. This is an extreme-value criterion, and it is the step that most
distinguishes this derivation from a naive signal-to-noise argument.

\begin{lemma}[Expected maximum of i.i.d.\ Gaussians]
\label{lem:extreme}
Let $Z_1,\dots,Z_n$ be i.i.d.\ $\mathcal{N}(0,1)$. Then
\[
\mathbb{E}\Big[\max_{1\le i\le n} Z_i\Big] \;\le\; \sqrt{2\ln n} \;+\; o(1) \quad \text{as } n\to\infty,
\]
and this bound is asymptotically tight: $\mathbb{E}[\max_i Z_i] = \sqrt{2\ln n}\,(1+o(1))$.
\end{lemma}

\begin{proof}[Proof of the upper bound]
For any $t \ge 0$, the standard Gaussian tail (Chernoff) bound gives $\Pr(Z_1 > t) \le
e^{-t^2/2}$: with $s=t$, $\Pr(Z_1>t) = \Pr(e^{sZ_1} > e^{st}) \le \mathbb{E}[e^{sZ_1}]e^{-st} =
e^{s^2/2 - st}$, minimized at $s=t$. A union bound over the $n$ variables gives $\Pr(\max_i Z_i
> t) \le \min(1,\, n e^{-t^2/2})$. Writing the expectation of a nonnegative random variable as
an integral of its tail,
\[
\mathbb{E}\Big[\max_i Z_i\Big] = \int_0^\infty \Pr\Big(\max_i Z_i > t\Big)\,dt
\;\le\; \int_0^{t^*} 1 \,dt + \int_{t^*}^\infty n e^{-t^2/2}\,dt,
\]
where $t^* = \sqrt{2\ln n}$ is chosen so the two bounds on the integrand meet ($n e^{-(t^*)^2/2}
= 1$). The first integral is exactly $t^* = \sqrt{2\ln n}$. For the second, the standard
Gaussian tail estimate $\int_a^\infty e^{-t^2/2}\,dt \le \tfrac{1}{a}e^{-a^2/2}$ (for $a>0$,
obtained by writing $e^{-t^2/2} \le \tfrac{t}{a}e^{-t^2/2}$ on $t\ge a$ and integrating exactly)
gives
\[
\int_{t^*}^\infty n e^{-t^2/2}\,dt \;\le\; \frac{n}{t^*}e^{-(t^*)^2/2} = \frac{1}{\sqrt{2\ln n}} \;\xrightarrow{n\to\infty}\; 0.
\]
Summing the two pieces gives $\mathbb{E}[\max_i Z_i] \le \sqrt{2\ln n} + o(1)$. The matching
lower bound requires a second-moment (Paley--Zygmund-type) argument and is omitted here; see
Boucheron, Lugosi \& Massart, \textit{Concentration Inequalities} \cite{blm2013}, Ch.\ 2, for
the complete two-sided result.
\end{proof}

Rescaling Lemma~\ref{lem:extreme} to $\mathcal{N}(\mu_{\text{other}},\sigma_{\text{other}}^2)$
variables and setting $n = M-1$ (the number of competing stored keys) gives the working
approximation used in the main paper:
\begin{equation}
\mathbb{E}\Big[\max_{i=1}^{M-1} S_{\text{other},i}\Big] \;\approx\; \mu_{\text{other}}(\eta) + \sigma_{\text{other}}(\eta)\sqrt{2\ln(M-1)}.
\label{eq:expmax}
\end{equation}

\section{Step 5: Solving for capacity}
\label{sec:step5}

Retrieval is (approximately, at the level of expectations rather than a proper tail bound on
failure probability) reliable when $S_{\text{true}}(\eta)$ exceeds the expected maximum
competitor, Equation~\ref{eq:expmax}. Define the normalized separation margin
\begin{equation}
z(\eta) \;=\; \frac{S_{\text{true}}(\eta) - \mu_{\text{other}}(\eta)}{\sigma_{\text{other}}(\eta)}.
\label{eq:margin}
\end{equation}
Setting $S_{\text{true}}(\eta) = \mu_{\text{other}}(\eta) + \sigma_{\text{other}}(\eta)\sqrt{2\ln(M-1)}$
and solving for $M$:
\begin{equation}
z(\eta) = \sqrt{2\ln(M-1)} \quad\Longleftrightarrow\quad M-1 = \exp\!\left(\frac{z(\eta)^2}{2}\right)
\quad\Longleftrightarrow\quad
\boxed{M_{\max}(\eta) \;\approx\; 1 + \exp\!\left(\frac{z(\eta)^2}{2}\right).}
\label{eq:mmax}
\end{equation}

\begin{proposition}[Structural form]
Equation~\ref{eq:mmax} states that capacity is exponential in the \emph{square} of a
normalized signal-to-noise-like quantity. This is the same structural form as modern Hopfield
networks' proven capacity $C \cong 2^{d/2}$ \cite{ramsauer2020}, though that bound is derived
via a Lyapunov energy-function argument (the Concave--Convex Procedure applied to a
log-sum-exp energy) over dense continuous patterns, not via hypergeometric statistics over a
sparse discrete code.
\end{proposition}

\section{An exact hypergeometric tail bound}
\label{sec:exacttail}

Equation~\ref{eq:mmax} matches only the \emph{expected} maximum competitor similarity, not a
probabilistic guarantee on retrieval failure -- a gap noted below in
Section~\ref{sec:limitations}. This section closes it with an exact, non-asymptotic tail bound
on the failure probability itself, derived directly from the hypergeometric distribution rather
than its Gaussian approximation, and valid at any finite $M$.

\subsection{A correlation a naive marginalization misses}
\label{sec:exacttail-pitfall}

Let $R$ denote the (random) number of $h_{\text{true}}$'s $K$ active positions that land among
the $\eta H$ flipped query positions. By Lemma~\ref{lem:hypergeom} (with $a=K$, $b=\eta H$), $R$
is exactly hypergeometric:
\[
R \sim \mathrm{Hypergeometric}(H,K,\eta H), \qquad
\Pr(R=r) = \frac{\binom{K}{r}\binom{H-K}{\eta H - r}}{\binom{H}{\eta H}}.
\]
Conditional on $R=r$, both the query's active-coordinate count and its similarity to
$h_{\text{true}}$ are \emph{deterministic}, not merely expected:
\[
k(r) = K + \eta H - 2r, \qquad s(r) = K - r,
\]
the realized versions of Equations~\ref{eq:kq} and \ref{eq:strue}, which recover
$k(\eta K)=K_q(\eta)$ and $s(\eta K)=S_{\text{true}}(\eta)$ only in expectation. Crucially,
$k(r)$ and $s(r)$ are perfectly correlated through the same draw of $r$: a query realization
with more of its true bits flipped off (large $r$) simultaneously has lower true-similarity
\emph{and} a different active count. A natural-looking but invalid shortcut is to hold $s(r)$
fixed at its unconditional expectation $S_{\text{true}}(\eta)=K(1-\eta)$ while still letting
$k(r)$ vary with $r$ inside the union bound over competitors: since $k(r)$ and $s(r)$ are
deterministic functions of the very same random variable, fixing one while randomizing the
other breaks their correlation and is not a valid marginalization of any well-defined random
process. Numerically, this shortcut understates the true failure probability by roughly four to
five orders of magnitude for $\eta \in [0.30, 0.40]$, converging to the correct value only as
$\eta$ approaches the collapse region (where $r$'s distribution concentrates and the distinction
between fixing $s(r)$ at $r$ or at $\mathbb{E}[r]$ stops mattering).

\subsection{Exact per-realization failure probability}

Fix one specific other stored key $h_j$ ($j \ne \text{true}$), itself an independent random
$K$-subset of $[H]$. Conditional on $R=r$, the query is a specific, realized $k(r)$-subset, and
its overlap with $h_j$ is exactly hypergeometric by Lemma~\ref{lem:hypergeom} (with $a=k(r)$,
$b=K$). Define the exact tail probability
\[
p_k(s) \;:=\; \Pr\big[\mathrm{Hypergeometric}(H,k,K) \ge s\big]
\;=\; \sum_{i=s}^{\min(k,K)} \frac{\binom{k}{i}\binom{H-k}{K-i}}{\binom{H}{K}}.
\]
(We use $\ge$ rather than strict $>$: an exact tie is conservatively counted as a failure, which
can only inflate the resulting probability and keeps Proposition~\ref{prop:corrected} below a
genuine upper bound regardless of how ties are broken at retrieval time.) Conditional on $R=r$,
the probability that this one specific competitor's similarity meets or exceeds
$h_{\text{true}}$'s is exactly $p_{k(r)}(s(r))$, and with $M-1$ independent competitors the
conditional failure probability is exactly
\[
\Pr[\text{fail} \mid R=r] \;=\; 1 - \big[1-p_{k(r)}(s(r))\big]^{M-1}.
\]
Averaging over $R$ gives the exact unconditional failure probability -- no Gaussian
approximation, no expectation-of-a-maximum heuristic, and no fixing of $s(r)$ at its mean:
\begin{equation}
P_{\text{fail}}(M,\eta) \;=\; \sum_{r=0}^{K} \Pr(R=r) \cdot
\Big\{ 1 - \big[1-p_{k(r)}(s(r))\big]^{M-1} \Big\}.
\label{eq:exactfail}
\end{equation}
Equation~\ref{eq:exactfail} is exact given the independence assumption of
Section~\ref{sec:limitations}; it involves only a finite sum over $r \in \{0,\dots,K\}$ and is
cheap to evaluate for any $H,K,\eta,M$.

\noindent\textbf{A small-tail approximation and a characteristic scale.} Away from the collapse
transition, $p_{k(r)}(s(r))$ is typically small, and
\[
\big[1-p_{k(r)}(s(r))\big]^{M-1} \;\approx\; \exp\big[-(M-1)\,p_{k(r)}(s(r))\big],
\]
so, conditional on $R=r$, retrieval probability decays approximately exponentially in $M$ with a
characteristic scale
\[
M^*_r \;\sim\; \frac{1}{p_{k(r)}(s(r))}.
\]
Intuitively: a dangerous competitor is individually unlikely at any single comparison, but there
are $M-1$ near-independent opportunities for one to occur, and their cumulative probability grows
with memory load -- the same ``many rare independent chances'' structure behind a Poisson
approximation, applied here to the union of $M-1$ competitor comparisons. This is an approximation
used only for intuition; Equation~\ref{eq:exactfail} itself requires no such approximation.

\subsection{No finite-size singularity: monotonicity and convexity in $M$}
\label{sec:smoothness}

Equation~\ref{eq:exactfail} is not just numerically well-behaved (Section~\ref{sec:exacttail-validation}
below) -- it is provably free of any finite-$M$ singularity of the kind a genuine attractor-collapse
memory cliff would produce. This is a structural property of the exact formula itself, independent of
the union bound derived in the next section, and is worth stating as a theorem in its own right.

\begin{theorem}[No finite-size singularity]
\label{thm:smoothness}
Fix $H$, $K$, and $\eta$, and suppose $0 < p_{k(r)}(s(r)) < 1$ for every $r$ with $\Pr(R=r)>0$ (against
any realized corruption level, a single competitor's failure is neither impossible nor certain).
Extend Equation~\ref{eq:exactfail} to continuous $M \ge 1$ via
\[
P_{\mathrm{ret}}(M,\eta) \;:=\; 1 - P_{\mathrm{fail}}(M,\eta) \;=\; \sum_{r=0}^{K} \Pr(R=r)\,
\big[1-p_{k(r)}(s(r))\big]^{M-1}.
\]
Then $P_{\mathrm{ret}}(M,\eta)$ is strictly decreasing and strictly convex in $M$:
\[
\frac{\partial P_{\mathrm{ret}}}{\partial M} < 0, \qquad \frac{\partial^2 P_{\mathrm{ret}}}{\partial M^2} > 0.
\]
\end{theorem}

\begin{proof}
Write $q_r := 1-p_{k(r)}(s(r)) \in (0,1)$ for each $r$ with $\Pr(R=r)>0$. Treating $M$ as a continuous
variable, $q_r^{M-1} = \exp[(M-1)\ln q_r]$, so
\[
\frac{\partial}{\partial M}\,q_r^{M-1} = q_r^{M-1}\ln q_r,
\qquad
\frac{\partial^2}{\partial M^2}\,q_r^{M-1} = q_r^{M-1}(\ln q_r)^2.
\]
Since $q_r \in (0,1)$, $\ln q_r < 0$ and $q_r^{M-1}>0$, so the first derivative is strictly negative
and the second, a square of a nonzero real number times a positive factor, is strictly positive.
$P_{\mathrm{ret}}(M,\eta)$ is a finite sum of these terms weighted by $\Pr(R=r)\ge0$ summing to $1$;
differentiation is linear and commutes with a finite sum, so
\[
\frac{\partial P_{\mathrm{ret}}}{\partial M} = \sum_{r} \Pr(R=r)\,q_r^{M-1}\ln q_r \;<\; 0,
\qquad
\frac{\partial^2 P_{\mathrm{ret}}}{\partial M^2} = \sum_{r} \Pr(R=r)\,q_r^{M-1}(\ln q_r)^2 \;>\; 0,
\]
each a weighted average, with at least one strictly positive weight, of terms that are all strictly
negative (respectively all strictly positive).
\end{proof}

\noindent\textbf{Interpretation.} Theorem~\ref{thm:smoothness} rules out, at the level of the exact
model, any finite-$M$ point at which retrieval probability could drop discontinuously or bend toward
an accelerating collapse: $P_{\mathrm{ret}}$ can only \emph{decelerate} as $M$ grows (convexity), on
top of always decreasing (monotonicity) -- graceful, non-catastrophic degradation, now proven rather
than only observed in simulation (Section~\ref{sec:exacttail-validation}). This is a property specific
to the \emph{explicit-key} retrieval mechanism analyzed throughout this note: failure accumulates from
more chances for some one unrelated stored key to accidentally resemble the query, not from the
appearance or disappearance of a dynamical attractor -- the latter being the mechanism behind a
genuine finite-size memory cliff in attractor-based (Hopfield-type) associative memories, and a
distinction this note does not claim to resolve for that broader model class (Section~\ref{sec:limitations}).

\subsection{A rigorous, closed-form sufficient bound}

Equation~\ref{eq:exactfail} is exact but implicit: it gives $P_{\text{fail}}$ as a function of
$M$, not $M$ as a function of a target failure probability $\delta$. We invert it via the union
bound, applied \emph{per realization of $r$} before averaging -- the order matters, and doing it
in this order is what keeps the resulting bound valid.

By Bernoulli's inequality, $1-(1-p)^n \le np$ for any $p\in[0,1]$ and integer $n \ge 0$. Applied
pointwise, for every $r$,
\[
1 - \big[1-p_{k(r)}(s(r))\big]^{M-1} \;\le\; (M-1)\,p_{k(r)}(s(r)).
\]
This is a deterministic inequality between two functions of $r$; taking $\mathbb{E}_R[\cdot]$ of
both sides preserves it, since expectation is monotone:
\begin{equation}
P_{\text{fail}}(M,\eta) \;\le\; (M-1) \cdot
\underbrace{\mathbb{E}_R\big[\,p_{k(R)}(s(R))\,\big]}_{=:\ \bar P(\eta)}.
\label{eq:pbar}
\end{equation}

\begin{proposition}[Corrected sufficient capacity bound]
\label{prop:corrected}
For any target failure probability $\delta \in (0,1)$, storing
\begin{equation}
M \;\le\; M_{\max}(\eta,\delta) \;:=\; 1 + \left\lfloor \frac{\delta}{\bar P(\eta)} \right\rfloor
\label{eq:mmax-exact}
\end{equation}
items guarantees $P_{\text{fail}}(M,\eta) \le \delta$ exactly, subject only to the independence
assumption of Section~\ref{sec:limitations} -- not to any Gaussian or large-$M$ asymptotic
approximation.
\end{proposition}

\begin{proof}
Immediate from Equation~\ref{eq:pbar}: $(M-1)\bar P(\eta) \le \delta$ whenever
$M - 1 \le \delta/\bar P(\eta)$, i.e.\ $M \le 1 + \lfloor \delta/\bar P(\eta) \rfloor$.
\end{proof}

Equation~\ref{eq:mmax-exact} has the same union-bound shape as a natural first attempt at this
formula, $1+\lfloor \delta/p_{K_q(\eta)}(S_{\text{true}}(\eta))\rfloor$, but with $p$ correctly
taken to be $\bar P(\eta) = \mathbb{E}_R[p_{k(R)}(s(R))]$ -- the per-realization tail probability
\emph{properly averaged} over $R$ -- rather than a single tail probability evaluated at the
mismatched pair $\big(K_q(\eta), S_{\text{true}}(\eta)\big)$, which (Section~\ref{sec:exacttail-pitfall})
treats the numerator and denominator of the same random draw as independently settable.

Two things stand out. First, the exact tail-based bound is dramatically more conservative than
the expected-maximum approximation -- by about seven orders of magnitude at $\eta=0.30$
($1.2\times10^{12}$ vs.\ $1.6\times10^{19}$), narrowing to about a factor of $120$ at
$\eta=0.42$. This gap is expected, not a contradiction between the two derivations: Equation~\ref{eq:mmax}
only requires the true match to beat the \emph{expected value} of the maximum competitor, a much
weaker requirement than controlling the actual \emph{probability} of failure to a small $\delta$
via a union bound over $M-1$ competitors. The two bounds answer different questions --
``typical-case margin'' versus ``guaranteed failure rate'' -- and are best read together:
Equation~\ref{eq:mmax} explains \emph{why} capacity is exponential in the squared margin (the
mechanism), while Equation~\ref{eq:mmax-exact} gives an actually-defensible number at a chosen
reliability level (the guarantee). Section~\ref{sec:limitations}'s prediction that a proper tail
bound ``would very likely give a somewhat smaller $M_{\max}$'' is confirmed, considerably more
starkly than that hedge anticipated.

Second, we check how loose the sufficient bound (Equation~\ref{eq:mmax-exact}) is relative to the
exact failure probability it bounds (Equation~\ref{eq:exactfail}), by comparing
$(M-1)\bar P(\eta)$ against $P_{\text{fail}}(M,\eta)$ directly (Table~\ref{tab:tightness}).

$\eta=0.42$, $M=4000$). This is the expected and honest behavior of a union bound: tightest
exactly in the well-separated regime where a capacity claim is most meaningful, and openly
announcing its own growing conservatism as the system approaches saturation rather than failing
silently.

\section{Limitations}
\label{sec:limitations}

Two assumptions are false by construction and are stated as such rather than absorbed silently.

\textbf{Independence.} Real stored keys are $W_{SH}$-projections of genuinely correlated
combinatorial objects (solved Sudoku grids share row/column/box structure), not independent
uniform random subsets. The observed collapse thresholds sit consistently at or slightly above
the predicted ones (Section~\ref{sec:validation}); a plausible explanation is that this real
correlation makes the worst-case competing key marginally less extreme than the independent
model assumes, though this has not been tested directly.

\textbf{The extreme-value step is a first-moment approximation, not a tail bound -- now
resolved.} Equation \ref{eq:expmax} matches the \emph{expected} maximum, not a high-probability
bound on it. Section~\ref{sec:exacttail} closes this gap with an exact, non-asymptotic
alternative (Equation~\ref{eq:exactfail}) and a corresponding rigorous sufficient bound
(Proposition~\ref{prop:corrected}), derived directly from the hypergeometric distribution rather
than the Gaussian approximation or the expected-maximum heuristic. As anticipated, the rigorous
bound gives a substantially smaller $M_{\max}$ at any fixed target failure probability --
by several orders of magnitude away from the collapse region (Table~\ref{tab:exacttail}) -- and
is itself provably tight in that same well-separated regime, growing conservatively (rather than
silently failing) only as $\eta$ approaches collapse (Table~\ref{tab:tightness}). Equation
\ref{eq:mmax} should now be read as characterizing the right \emph{mechanism} -- exponential
capacity in the squared separation margin, hence a sharp rather than gradual collapse -- while
Equation~\ref{eq:mmax-exact} is the bound to use for an actual reliability guarantee at a chosen
$\delta$. Both bounds still share the independence assumption below, which remains open.

\section{Outlook: an asymptotic large-deviation phase boundary}
\label{sec:outlook}

Theorem~\ref{thm:smoothness} rules out a finite-$M$ singularity at fixed $H$. It does not rule out
an asymptotically sharp threshold if $H$ and $M$ are taken to infinity together in a suitable
exponential scaling regime -- the same sense in which Shannon's channel coding theorem
\cite{coverthomas} produces a sharp rate/capacity boundary only in the block-length limit, never at
any finite block length. We record the expected shape of this limit here as motivation for future
work, not as a proven result: the rate function below is not derived from the hypergeometric tail,
and the statement that follows is conditional on its existence in the assumed form.

Let $\rho = K/H$ and suppose the per-competitor tail probability admits a large-deviation form
\begin{equation}
p_H(\eta,\rho) \;\overset{H\to\infty}{\sim}\; \exp\big[-H\,I(\eta,\rho)\big]
\label{eq:ratefunction}
\end{equation}
for some rate function $I(\eta,\rho)\ge0$ (large-deviation forms of this kind are standard for tail
probabilities of hypergeometric-type sampling, by analogy with Sanov's and Cram\'er's theorems for
sampling without replacement, but $I(\eta,\rho)$ is not derived here). If the number of stored
memories scales exponentially with $H$, $M=\exp(\alpha H)$, then substituting
Equation~\ref{eq:ratefunction} into $P_{\mathrm{ret}}\approx[1-p_H(\eta,\rho)]^{M-1} \approx
\exp[-(M-1)p_H(\eta,\rho)]$ (the small-tail approximation above) gives, to leading order,
\begin{equation}
P_{\mathrm{ret}} \;\approx\; \exp\Big\{-\exp\big[H\big(\alpha - I(\eta,\rho)\big)\big]\Big\},
\label{eq:doubleexp}
\end{equation}
a sharp threshold at
\begin{equation}
\alpha_c(\eta,\rho) \;=\; I(\eta,\rho): \qquad
P_{\mathrm{ret}} \xrightarrow{H\to\infty}
\begin{cases}
1 & \alpha < I(\eta,\rho) \quad\text{(reliable retrieval)}\\
0 & \alpha > I(\eta,\rho) \quad\text{(competitors overwhelm retrieval)}
\end{cases}
\label{eq:phaseboundary}
\end{equation}
with critical scaling at $\alpha=I(\eta,\rho)$.

This is not a contradiction of Theorem~\ref{thm:smoothness}: a finite-$H$ curve that is provably
smooth and convex at every finite size can still become arbitrarily sharp in a singular joint
limit. The correct summary is \emph{no finite-size attractor-collapse cliff}, not \emph{no
asymptotic phase boundary under any scaling}. Deriving $I(\eta,\rho)$ explicitly from the
hypergeometric tail -- turning Equation~\ref{eq:phaseboundary}'s qualitative picture into an
explicit phase boundary in $(\eta,\rho,\alpha)$ space -- would connect this note's finite-size
theory directly to the large-deviation/statistical-mechanics literature cited below, and is left
to future work.

\section{Relation to the wider literature}

This derivation belongs to a family of results sharing one underlying question: does a correct
answer stand out against the \emph{extreme} value among exponentially or combinatorially many
near-random alternatives? The same skeleton, worked out through different technical routes,
underlies Shannon's channel coding theorem \cite{coverthomas}, the Random Energy Model in
spin-glass theory \cite{mezardmontanari2009}, Gardner's perceptron capacity
\cite{gardner1988}, and the classical Amit--Gutfreund--Sompolinsky analysis of Hopfield network
capacity \cite{ags1987}. Kanerva's original capacity analysis for sparse distributed memory
\cite{kanerva1988} is the closest existing derivation in spirit to this one -- also a sparse
binary code, also analyzed via combinatorial (there, Hamming-ball volume) arguments -- though
via a different geometric route than the hypergeometric-overlap statistics used here.

\section{Appendix: An independent derivation of MESH's heteroassociative overlap formula}
\label{sec:mesh-derivation}

Section 4.5 of the main paper ties an empirically measured capacity ceiling to a specific
published result, MESH's Theorem 5.3 \cite{sharma2022}: for $N_{\mathrm{patts}} > N_H$
stored patterns, pseudoinverse-learned heteroassociation from the hidden (scaffold) layer to the
feature layer gives partial reconstruction, with the dot product between each stored feature
pattern and its (pre-sign-nonlinearity) reconstruction equal to $N_H/N_{\mathrm{patts}}$,
averaged across patterns. We derive this independently here, from elementary linear algebra and
one distributional assumption, rather than only citing it.

\paragraph{Setup.} Let $H\in\mathbb{R}^{N_H\times N_{\mathrm{patts}}}$ have columns $h^\mu$,
$\mu=1,\dots,N_{\mathrm{patts}}$, the scaffold's predefined hidden-layer states, and let
$F\in\mathbb{R}^{N_F\times N_{\mathrm{patts}}}$ have columns $f^\mu$, the arbitrary content
patterns heteroassociated with them. Assume: (i) $N_{\mathrm{patts}}>N_H$ and $H$ has full row
rank $N_H$ (guaranteed for the scaffold's own predefined states by construction
\cite{sharma2022}, independent of $F$); (ii) the columns $f^\mu$ are independent, zero-mean, and
each satisfies $(f^\mu)^\top f^\mu=N_F$ exactly (e.g.\ i.i.d.\ random $\{-1,1\}$ patterns), and
are independent of $H$. Heteroassociative pseudoinverse learning sets $W_{FH}=FH^+$, and
presenting the exact hidden state $h^\mu$ recovers $\hat f^\mu = W_{FH}h^\mu = FH^+h^\mu$.

\begin{proposition}[MESH's heteroassociative overlap formula, re-derived]
\label{prop:mesh-rederived}
Under assumptions (i)--(ii),
\[
\frac{1}{N_{\mathrm{patts}}}\sum_{\mu=1}^{N_{\mathrm{patts}}}
\mathbb{E}\!\left[\frac{(f^\mu)^\top \hat f^\mu}{N_F}\right] \;=\; \frac{N_H}{N_{\mathrm{patts}}}.
\]
\end{proposition}

\begin{proof}
Since $H$ has full row rank, its right pseudo-inverse is $H^+=H^\top(HH^\top)^{-1}$, satisfying
$HH^+=I_{N_H}$. Writing $h^\mu=He_\mu$ ($e_\mu$ the $\mu$-th standard basis vector of
$\mathbb{R}^{N_{\mathrm{patts}}}$),
\[
\hat f^\mu = FH^+He_\mu = Fc^\mu, \qquad c^\mu := Pe_\mu, \qquad P:=H^+H\in\mathbb{R}^{N_{\mathrm{patts}}\times N_{\mathrm{patts}}}.
\]
$P$ is the orthogonal projector onto the row space of $H$: symmetric and idempotent, since $HH^\top$
is symmetric,
\[
P^\top = H^\top\big((HH^\top)^{-1}\big)^\top H = H^\top(HH^\top)^{-1}H = P, \qquad
P^2 = H^\top(HH^\top)^{-1}\big(HH^\top(HH^\top)^{-1}\big)H = P,
\]
with $\mathrm{rank}(P)=\mathrm{rank}(H)=N_H$. The vector $c^\mu$ is column $\mu$ of $P$, so its own
$\mu$-th entry is the diagonal element $c^\mu_\mu = P_{\mu\mu}$. Expanding the reconstruction over
the pattern basis,
\[
\hat f^\mu = \sum_{\nu=1}^{N_{\mathrm{patts}}} c^\mu_\nu f^\nu = c^\mu_\mu f^\mu + \sum_{\nu\ne\mu} c^\mu_\nu f^\nu,
\]
so $(f^\mu)^\top\hat f^\mu = c^\mu_\mu(f^\mu)^\top f^\mu + \sum_{\nu\ne\mu}c^\mu_\nu(f^\mu)^\top f^\nu
= c^\mu_\mu N_F + \sum_{\nu\ne\mu}c^\mu_\nu(f^\mu)^\top f^\nu$. Taking expectation over $F$ (with
$H$, hence $c^\mu$, independent of $F$), every cross term $\mathbb{E}[(f^\mu)^\top f^\nu]=0$ for
$\nu\ne\mu$ by assumption (ii), leaving
\[
\mathbb{E}\!\left[\frac{(f^\mu)^\top \hat f^\mu}{N_F}\right] = c^\mu_\mu = P_{\mu\mu}.
\]
Averaging over all $N_{\mathrm{patts}}$ patterns,
$\frac{1}{N_{\mathrm{patts}}}\sum_\mu P_{\mu\mu} = \mathrm{tr}(P)/N_{\mathrm{patts}}$. $P$ is an
orthogonal projector, so its eigenvalues are all $0$ or $1$ and its trace equals its rank:
$\mathrm{tr}(P)=\mathrm{rank}(P)=N_H$. Hence the average equals $N_H/N_{\mathrm{patts}}$.
\end{proof}

We verified Proposition~\ref{prop:mesh-rederived} numerically (random Gaussian $H$, i.i.d.\
$\{-1,1\}$ columns for $F$) across four $(N_H,N_{\mathrm{patts}},N_F)$ triples spanning an order
of magnitude in each dimension; measured and predicted overlap agreed to at least three decimal
places in every case (e.g.\ $N_H{=}150$, $N_{\mathrm{patts}}{=}1000$: measured $0.1500$ vs.\
predicted $0.1500$).

\paragraph{Discussion.} The result depends on $H$ only through its rank, via $\mathrm{tr}(P)=N_H$
-- not on any property of $F$ beyond assumption (ii)'s independence and normalization. This is why
Theorem 5.3, unlike MESH's Theorem 5.1 (Section 4.5 of the main paper), requires no full-rank
assumption on the \emph{content} matrix $F$: the ceiling here is set entirely by the scaffold side
($N_H$ relative to $N_{\mathrm{patts}}$), and the content patterns need only be independent and
appropriately normalized. Between the two theorems, MESH's own heteroassociation theory covers
both directions in which a pseudoinverse-learned heteroassociative map can be starved of rank: too
few scaffold dimensions relative to the number of patterns (Theorem 5.3, re-derived here), or too
little independent information in the content itself (Theorem 5.1, violated by real images in
Section 4.5 of the main paper).
